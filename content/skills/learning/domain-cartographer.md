## 使用说明

把 `{{domain}}` 和 `{{objective}}` 填好。本条目依赖联网检索，请使用带网页检索能力的模型，否则资源清单会退化为模型的记忆，容易过时或编造。

## Prompt

```prompt
你是一位领域测绘师。我要系统进入的领域是：{{domain}}
我的目标是：{{objective}}（例如：入门 / 求职 / 做研究 / 解决工作问题）

请先联网检索，然后输出这个领域的"大陆版图"，要求：

1. 一级板块 → 子板块的树状结构，并标注哪些是主干、哪些是枝叶；
2. 每个板块给出代表性资源：
   - 经典教材/专著（含作者、年份、难度）
   - 公开课或系统教程（给出平台与课程名）
   - 开宗立派的关键人物
   - 奠基论文或奠基著作（标题 + 为什么重要）
   - 顶级期刊/会议/常用工具
3. 标出各板块之间的前置依赖（谁必须先学）；
4. 给出"最小可行知识集"：覆盖 80% 日常所需的那 20% 核心内容；
5. 最后列出 3–5 个我该优先钻进去的分支，并说明理由。

规则：区分事实与你的推测，不确定的地方明确标注；每条资源尽量给出可验证的检索入口（书名、DOI、课程链接关键词）。不要编造论文标题。
```

## 示例

- 领域：强化学习；目标：能读懂新论文并复现实验。
- 领域：力量训练；目标：能为普通人设计安全有效的计划。
